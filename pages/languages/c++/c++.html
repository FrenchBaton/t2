1. Введение в C++

Что такое C++?

C++ — это мощный компилируемый язык программирования общего назначения. Он используется для создания операционных систем, игровых движков, браузеров и высоконагруженных приложений.

Первая программа

Давайте напишем нашу первую программу на C++.
Программа выведет на экран текст «Привет, мир!».
1 #include <iostream>
2 int main() {
3     std::cout << "Привет, мир!";
4     return 0;
5 }
Объект std::cout выводит данные на экран с помощью оператора <<. Строка текста заключается в двойные кавычки.
💡 Важно
Регистр символов имеет значение: cout и Cout — это разные вещи. В конце каждой инструкции ставится точка с запятой.

Комментарии в C++

Комментарии нужны, чтобы делать код понятнее для себя и других разработчиков. В C++ комментарии начинаются с символов //.
1 // Это однострочный комментарий
2 std::cout << "Привет, мир!"; // Комментарий после кода
💡 Совет
Хорошие комментарии делают код легче для чтения и поддержки.
