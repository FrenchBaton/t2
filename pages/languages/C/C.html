1. Введение в C#

Что такое C#?

C# — это современный объектно-ориентированный язык программирования от компании Microsoft, созданный для платформы .NET. Он широко применяется для разработки игр на движке Unity, веб-сервисов, корпоративного ПО и десктопных приложений.

Первая программа

Давайте напишем нашу первую программу на C#.
Программа выведет на экран текст «Привет, мир!».
1 using System;
2 class Program {
3     static void Main() {
4         Console.WriteLine("Привет, мир!");
5     }
6 }
Метод Console.WriteLine() выводит данные на экран с переносом строки. Текст обязательно заключается в двойные кавычки.
💡 Важно
Регистр символов имеет значение: Console и console — это разные вещи. В конце каждой инструкции ставится точка с запятой.

Комментарии в C#

Комментарии нужны, чтобы делать код понятнее для себя и других разработчиков. В C# однострочные комментарии начинаются с символов //.
1 // Это однострочный комментарий
2 Console.WriteLine("Привет, мир!"); // Комментарий после кода
💡 Совет
Хорошие комментарии делают код легче для чтения и поддержки.
