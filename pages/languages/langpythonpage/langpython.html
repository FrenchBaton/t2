1. Введение в Python

Что такое Python?

Python - это высокоуровневый язык программирования с простым синтаксисом и читаемым кодом. Он подходит для начинающих и используется в самых разных областях: от веб-разработки и анализа данных до искусственного интеллекта и автоматизации.

Первая программа

Давайте напишем нашу первую программу на Python.
Программа выведет на экран текст «Привет, мир!».
1 print(Привет, мир!)
Функция print() выводит данные на экран. Строка текста заключается в кавычки.
💡 Важно
Регистр символов имеет значение: print и Print - это разные вещи.

Комментарии в Python

Комментарии нужны, чтобы делать код понятнее для себя и других разработчиков. В Python комментарии начинаются с символа #.
1 # Это однострочный комментарий
2 print(Привет, мир!) # Комментарий после кода
💡 Совет
Хорошие комментарии делают код легче для чтения и поддержки.
