1. Введение в JavaScript

Что такое JavaScript?

JavaScript — это популярный язык программирования, который делает веб-страницы интерактивными. Он работает прямо в браузере, а также используется для создания серверов, мобильных и десктопных приложений.

Первая программа

Давайте напишем нашу первую программу на JavaScript.
Программа выведет в консоль текст «Привет, мир!».
1 console.log("Привет, мир!");
Метод console.log() выводит данные в консоль разработчика. Текст заключается в двойные или одинарные кавычки.
💡 Важно
Регистр символов имеет значение: console и Console — это разные вещи. В конце инструкций принято ставить точку с запятой.

Комментарии в JavaScript

Комментарии нужны, чтобы делать код понятнее для себя и других разработчиков. В JavaScript однострочные комментарии начинаются с символов //.
1 // Это однострочный комментарий
2 console.log("Привет, мир!"); // Комментарий после кода
💡 Совет
Хорошие комментарии делают код легче для чтения и поддержки.
